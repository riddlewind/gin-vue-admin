## 通读 gin-vue-admin 全项目，产出「快速上手 + 二次开发」指南

核对过的关键事实（以代码为准，不以文档为准）：

- 版本：`web/package.json` 2.9.2，`server/go.mod` go 1.24.0（toolchain go1.24.2）；README 写 >=1.22 已偏保守。前端 Vite 8 + Vue 3.5 + Element Plus 2.13。
- 后端端口 8888，前端 8080，`.env.development` 里 `VITE_BASE_API=/api` 代理到 `http://127.0.0.1:8888`。
- 分层链路：`router → api → service → model`，四层各有 `enter.go` 做组合注册（`RouterGroupApp` / `ApiGroupApp` / `ServiceGroupApp`）。
- 业务代码挂载钩子（二次开发必改的两处空实现）：
  - `server/initialize/gorm_biz.go` 的 `bizModel()` —— 业务表 AutoMigrate（当前是空 `db.AutoMigrate()`）

- 统一响应 `{code, data, msg}`，`code===0` 为成功；分页 `{page, pageSize, total, list}`。
- 鉴权：`PrivateGroup.Use(JWTAuth()).Use(CasbinHandler())`，header 用 `x-token` + `x-user-id`。casbin 策略不在代码里，靠「API 管理」登记接口 + 「角色管理」授权，否则 403。

- 插件双轨：v1 手写 `CreateXxxPlug`（`initialize/plugin_biz_v1.go`），v2 靠 `init()` 自注册（`initialize/plugin_biz_v2.go` + `server/plugin/register.go`）。现有插件：announcement / auto / email / plugin-tool。
- 代码生成器：前端 `web/src/view/systemTools/autoCode`，模板在 `server/resource/package/*.tpl` 与 `server/resource/plugin/*.tpl`；支持「从数据库表生成」和「prompt 让 AI 生成」两条路。

### 抓到一个真实 bug（重要教学案例）

`Error 1292 (22007): Incorrect datetime value: '0000-00-00' for column 'created_at'`
